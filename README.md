# Spustenie projektu

Na zariadení musí byť nainštalovaný Bun (https://bun.sh) alebo Node.js a PHP 8.5 s Composerom.
Pre inštaláciu je treba použiť príkaz `composer run setup` ktorý nainštaluje všetky závislosti.
Potom pripravíme databázu cez `composer run seed`.

Laravel dev server na porte 8000 spustíme štandardne `composer run dev`.
